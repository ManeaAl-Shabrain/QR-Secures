# Project History

## Practicum phase

The Fall 2025 work focused on malicious URL detection. The team compared CNN, GRU, and CNN-LSTM models, selected the CNN, added heuristic checks and live SSL/TLS inspection, and combined the signals with a weighted decision rule. The practicum report described a command-line prototype and listed a graphical or mobile interface as future work.

## Capstone phase

Winter 2026 reports describe interface refinement, repeated demonstrations, result presentation, mobile packaging, deployment planning, and final-defense preparation. The academic defense report frames this as an Android APK extension of the practicum system.

## Base44 application phase

Later materials document a broader Base44 web application. It adds accounts, QR and manual scanning, LLM-assisted analysis, scan history, dashboards, community reporting, investigations, watchlists, incident-response settings, user management, and Slack integration.

This phase introduced a substantial architectural change. The repository therefore treats the CNN detector and Base44 application as connected stages with different evidence bases.

## Curated academic artifacts

The repository retains one final practicum report, one capstone defense report, and one capstone presentation. Duplicate documents, templates, logbooks, progress reports, and script variants remain outside the repository because they repeat content or include administrative and personal details that do not improve public understanding.
