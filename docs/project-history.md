# Project History

## Practicum

The Fall 2025 work focused on malicious URL detection. The team compared CNN, GRU, and CNN LSTM models and selected the CNN. The detector also checked URL patterns and SSL certificates before combining the results into one score. The practicum report described a command line prototype and suggested a graphical or mobile interface as future work.

## Capstone

The Winter 2026 reports describe interface improvements, repeated demonstrations, clearer results, mobile packaging, deployment planning, and preparation for the final defense. The defense report presents this stage as an Android application built from the practicum work.

## Base44 application

Later material describes a broader Base44 web application. It includes accounts, QR and manual scanning, language model analysis, scan history, dashboards, community reports, investigations, watchlists, incident response settings, user management, and Slack integration.

This stage changed the system architecture. The repository therefore presents the CNN detector and the Base44 application as related work with separate evidence.

## Files kept in this repository

The repository keeps one final practicum report and one capstone defense report. Duplicate documents, templates, logbooks, progress reports, and script drafts remain outside the public repository because they repeat information or contain private academic details.
